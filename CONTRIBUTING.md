# Contributing

Use Node 24 and the lockfile in apps/web. Follow AGENTS.md. Run lint, typecheck, unit tests and the Workers build. Run browser tests against a local preview; set BASE_URL only when intentionally checking a deployed instance.

Keep evaluation references out of application imports. Every extracted fact must retain an exact page passage. Add a regression case for domain-rule changes. Never replace uncertain extraction with invented fixture values.

Stay on free Cloudflare services unless the owner explicitly changes the cost constraint. Do not activate R2 billing, paid Workers or hosted model calls as a routine fix. No secrets, private originals or browser session artifacts belong in Git.
