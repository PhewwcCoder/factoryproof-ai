# FactoryProof video production

The existing concept film, source, audio, illustrations, renders, models and deliverables are in `factoryproof-video/`. That folder retains its own Git repository and existing uncommitted work. Run video commands from that directory.

Production reference checkouts are under `references/`: HyperFrames, Remotion skills, Taste, and Motion Primitives. Shared installed agent skills remain in the workspace skill directories so agents can still discover them.

Large generated video artifacts and third-party reference checkouts are excluded from the application Git repository. No video source or deliverable was intentionally deleted.
